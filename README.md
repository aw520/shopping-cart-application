# 🛒 Shopping Cart Application

A responsive React-based web application that allows users to browse products, manage their shopping cart, and view order summaries in real time.  
The project demonstrates clean frontend architecture using **React**, **Redux**, and **Axios** for state management and API communication.

---

## ✨ Key Features

- **🛍️ View Products**
  - Displays a catalog of products with name, price, and description.
  - Fetches product data dynamically via Axios from a sample API.

- **➕ Add to Cart**
  - Add items to the shopping cart with quantity control.
  - Automatically updates the total item count and total price.

- **🔄 Adjust Quantities**
  - Increase or decrease product quantities directly within the cart.

- **❌ Remove Items**
  - Remove specific items from the cart instantly.

- **💰 Real-Time Cart Summary**
  - Displays the total number of items and total price, updating automatically as the cart changes.

- **🚫 404 Handling**
  - Includes a custom 404 page for undefined routes to enhance user experience.

- **📄 Pagination Support**
  - Adds client-side pagination with URL state (?page=) to preserve page position when navigating between views.
